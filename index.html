Version 1.2.0

Latest
  • New
    Remember your speed — the new Remember Playback Speed setting resumes at the speed you last used instead of resetting to the default every time.
  • New
    Per-title speeds — with Remember Speed Per Title enabled, every show and movie keeps its own speed, so a documentary at 1.5x doesn't follow you into a film you want at normal speed. All episodes of a series share one speed.
  • Languages
    Available in every language — the new speed-memory settings ship translated in all 78 supported languages, not just English.
  • Audio
    Guaranteed natural pitch — pitch correction is now set explicitly on every speed change rather than relying on the browser default, so the 1.1.0 audio problem cannot come back.
  • Languages
    Typing a decimal comma now works — in the 33 languages that write 1,85 rather than 1.85, the custom speed box and the quick-speed examples silently produced the wrong values. Both now work.
  • Languages
    Fixed missing translation — the "Open a Netflix video to control speed" status appeared in English in every language.
  • Languages
    Fixed Serbian text — three messages displayed raw __ВАР1__ markers instead of the speed values.
  • Languages
    Much better Korean — 16 labels were mistranslated in earlier releases: “Theme” read as topic, “Light” as illumination, “Reset” as put down again, and “Not on Netflix” said the title was unavailable. All corrected, and the wording now matches Korean interface conventions throughout.
  • Improved
    Tidier footers — the version label has been removed from the popup and Settings pages, where it could show an out-of-date number.
  • Fixed
    Speed indicator no longer flashes unprompted — a leftover timer could flash the overlay after you had already returned to normal speed.
  • Fixed
    Player status after closing a video — with more than one video on the page, closing one could leave the popup reporting no active video while playback continued.
  • Fixed
    Open tabs survive an update — updating the extension no longer leaves already-open Netflix tabs unresponsive until you reload them.

Version 1.1.1

  • Fixed
    Netflix navigation — video detection now keeps watching the full document, so the controller continues working when Netflix replaces the player during in-app navigation or episode changes.
  • Improved
    Efficient document monitoring — retains the video-only mutation filtering and 200 ms debounce, avoiding full video scans for unrelated page updates.
  • Fixed
    Accurate player status — the popup now clearly indicates when a Netflix page has no active video and disables controls until playback is available.
  • Fixed
    Working default speed — a new Netflix page now starts at the speed selected in Settings instead of reusing a stale speed from a previous session.
  • Improved
    Live overlay settings — enabling or disabling the on-video controls now takes effect immediately during playback.
  • Fixed
    Reliable shortcuts after reset — Reset to Defaults now restores the working keyboard shortcut format.
  • Audio
    Natural audio pitch and efficient speed recovery — custom speeds preserve normal voice pitch and react to native playback-rate changes without a continuous polling loop.
  • Reliability
    Seek-safe playback recovery — speed restoration now waits for Netflix to finish rebuilding media and subtitle timing after a seek, preventing lag and subtitle desynchronization.

Version 1.1.0

  • Performance
    Faster and smoother — the extension now runs more efficiently so it won't slow down your browsing.
  • Audio
    Better audio at high speeds — no more weird sound distortion when watching at 2x, 3x, or faster.
  • Reliability
    More reliable — speed changes stick better during seeking and buffering.
  • Performance
    Smaller performance footprint — uses less CPU and memory while you watch.

Correction (added in 1.2.0): the audio note above was wrong. This release shipped pitch correction switched off rather than on, which is what caused the distorted, high-pitched audio reported after it. 1.1.1 removed the offending code and restored correct audio; 1.2.0 now sets pitch correction explicitly so it cannot regress again.
